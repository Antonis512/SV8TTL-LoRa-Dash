Discovering and connecting available radios…

      
Checks attached USB serial devices first, then discovers saved Bluetooth radios. Only saved radio identities are connected. Discovery does not guarantee connection.

Send to Multiple

  
    
    
Send a message to selected contacts or channels through their own radios. Sequential sending waits for results; pause and continue a saved chain later. Disabling stops pending dispatch.

    
    
Default 3 seconds after the result; this does not guarantee quiet radio traffic. Repeats do not prove recipient delivery.

    
    
Default 5 seconds. Wait for a heard repeat or this timeout, then pause before the next message. No repeat means delivery is unconfirmed. Applies to new channel sends in a chain. Start Send to multiple from the button between the Users pills in Chat.

    

    



  



  
Message Split

  
    
    
Split messages exceeding the radio limit into separate parts. Disabling rejects new oversized messages without removing your draft; already queued parts may finish.

    
    
Wait for the previous part's result or observation timeout, then wait this interval (default 5 seconds). Radio retries must finish first. Send to multiple also respects the pause before the next message.
