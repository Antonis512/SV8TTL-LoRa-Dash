This APK contains the MT loading fixes described in ../MT-LOADING-2026-11-05.md.

IMPORTANT: This APK uses a different debug signing certificate from the published 0.10.25 APK. Android will reject an in-place update of that installation. Preserve the installed app and export a Full App Backup before considering migration. The original signing key is required for an update that keeps the existing installation.
