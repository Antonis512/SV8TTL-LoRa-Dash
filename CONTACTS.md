# Contacts — 0.10.21 local preview

Contacts is a separate tab between Nodes and Chat. The bottom menu scrolls horizontally on narrow screens; arrows indicate hidden tabs. A local debug APK is available as version 0.10.21 (48); it has not been published to GitHub.

Create a profile with just a name, surname, alias or preferred display name. Optional fields include a photo, organization/club and role, labelled callsigns (default label **Radio Amateur**), phone numbers, emails, addresses, typed custom fields, dated notes and related Log entries. There are no dedicated fields for where/how you met, preferred contact method, languages or links. A user-created custom field can have text, number, date or link type.

Favorites and multiple categories are independent. Search covers profile fields, categories, custom fields, notes and assigned nodes; it ignores capitalization and Greek accents, normalizes phone formatting and tolerates small spelling errors. Results show the matching field, and the list reports matches hidden by filters. Sorting and contact-list filters are remembered on this phone and included in the settings portion of Full App Backup.

Assign multiple MC/MT nodes in the profile editor or use **Assign to Contact** from node actions in Nodes or Chat. A shared radio can belong to several contacts, with an association (owner/operator/maintainer/shared) and description for each. Name-only MeshCore senders are explicitly unverified. A contact's node cards use the same action controls as Nodes and can be filtered by network, receiving device, role, infrastructure/users, favorites, heard settings, last-heard time and messageability; sort by name, hops or last heard. Last-heard time describes the radio, not the person's availability.

**Unassign Node** only removes an association. **Forget Node** removes the radio's local history and associations but retains the person's profile. **Delete Contact** moves the profile to Deleted contacts, where Restore undoes the deletion. It does not delete Android address-book entries or radio messages. **Find duplicates** compares names, callsigns, phone numbers and emails. Merge opens an editable combined profile, retains conflicting scalar values as custom fields and moves the other profile to Deleted contacts when saved.

**Tools and import → Import from Android** opens the system contact picker. It imports only the selected contact; it requests no broad address-book permission. Fields are reviewed before saving. Optional linking stores an Android contact reference; refreshing requires selecting the Android contact again and explicitly choosing fields to replace. There is no background or two-way synchronization. Android contacts are never edited or deleted by LoRa Dash. If the selected provider permits only basic details, the import screen says so.

Call opens Android's dialer with the number. SMS and email open their respective apps. Share lets the user choose fields and an optional photo; private notes are unchecked by default. JSON export includes complete selected profiles, embedded photos and node assignments. JSON import offers record selection and an explicit option to replace matching IDs; different IDs can be merged afterwards. Photos are stored as portable JPEG thumbnails rather than temporary Android file links.

**Full App Backup includes the entire Contacts store**, including photos, all profile fields, categories, favorites, dated notes, Log references, node assignments, Android link references and deleted profiles retained for undo. Backup format 5 adds `contacts`; formats 1–4 remain readable. Contacts restore within the same database transaction as the other app data, and older records do not overwrite newer edits. Android link references may need to be reselected on a new phone; profile data and photos remain usable offline.

Validation: `tests/contacts.cjs` covers browser workflows, errors and phone-width layouts. `HistoryInstrumentation` contains database migration, full-backup round-trip, photo/assignment restoration, old-backup compatibility, merge and malformed-import checks. Device checks still need to exercise Android pickers, external call/SMS/email apps, actual Full App Backup restoration, physical radios and gesture/three-button navigation. Compile-only Gradle tasks do not package an APK.

Deleted contacts can also be permanently erased from the Deleted contacts window. Only an anonymous deletion marker is retained to prevent an older backup from immediately restoring the erased profile. Previously exported backup files are independent copies.
