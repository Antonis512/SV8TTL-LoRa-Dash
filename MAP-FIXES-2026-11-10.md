# Node depiction fixes — 10 November 2026

Implemented locally following the official-source review in `MAP-COMPARISON-2026-11-10.md`. No APK was built or published for these changes.

## Positions and provenance

`NodePosition` keeps a complete coordinate pair, sharing precision, position-report/advertisement time, GPS fix time, phone receipt time and source. MT decoding retains Position fields 4, 7 and 23, rather than discarding them. MC contact coordinates keep their own 1e6 scale and advertised timestamp; self-info positions are identified as the connected radio's configured location. They are not assigned inferred MT precision or GPS fix timestamps.

Missing axes cannot combine with an older axis to create an invented fix. Both supplied zero axes remain the protocol's unknown-location sentinel; the equator and prime meridian are valid when the other supplied axis is nonzero. Invalid ranges, absent/broadcast MT node identities and implausibly future times are rejected or marked unknown.

An older dated fix cannot replace a newer one. An undated downloaded snapshot cannot displace a dated position. For MT reduced-precision reports, a previously known more precise point is retained only if it belongs to the same transmitted coarse cell. A different cell can move the marker. Existing legacy coordinates have unknown precision: the first new precision-bearing report supplies that missing metadata rather than incorrectly treating every old coordinate as precise. No exact coordinate is reconstructed from a coarse report.

The in-memory session and background database installation use the same policy. Results selected from previously persisted positions are reconciled on main after commit. MT node snapshots still install off the UI thread. Reconnect generations prevent old queued updates from replacing current session state.

## Persistence and map selection

Database schema 19 adds metadata columns to map nodes and trail records without removing existing locations or history. Existing rows keep unknown report/GPS times and their known legacy receipt time. Backups export and restore the new fields; older backups remain accepted with missing fields unknown. Existing-node backup merging remains additive.

All devices selects valid positions before missing positions, protects same-cell better-known MT coordinates, compares known position times, then uses the connected receiver and observation receipt time for remaining unknown/equal-time cases. A stable receiver-ID tie break removes dependence on database row order. An explicit Device filter continues to show that receiver's own observation. Unknown age is displayed as unknown, not silently treated as a fresh GPS report.

## Rendering

- Standard MT sharing precision 10–19 draws a geographic uncertainty circle with the official app's radius mapping (approximately 46 m at 19 bits, 365 m at 16, 2.92 km at 13 and 23.35 km at 10). Full/unknown precision and MC positions do not acquire guessed circles. Coincident identical circles are drawn once. Circle rings remain closed and continuous across the date line.
- The user can hide/show these circles with **Show shared-position uncertainty circles**. This local display preference does not change radio broadcasts.
- Nodes within five metres form a stable geographic stack with a visible count and a chooser listing each node ID/name. Selecting a node or exact receiver opens its actual reported coordinate. The connected radio is preferred for the top of its own stack. Markers are not given fabricated geographic offsets.
- Popups show coordinates, receiver, provenance, precision, separate report/advertisement and GPS times when present, and independent phone receipt time. Unknown-age markers have a dashed border. The connected MC radio's configured location is now included even if it is not in the downloaded contact list.
- A retained precise location does not create a new precise trail sample merely because a coarse report arrived. Approximate MT reports do not trigger exact-location geofence notifications. Existing stored alert history remains available.
