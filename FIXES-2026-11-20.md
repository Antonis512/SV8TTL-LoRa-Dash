# Chat, Nodes and Map fixes — 20 November 2026

- Meshtastic direct-only filtering now excludes nodes reporting positive hop counts even when an older signal sample reports zero hops. MeshCore incoming reception and outgoing route length remain separate.
- Normal channel Chat has Send position above Send, using the phone position confirmation dialog and the selected radio/channel. Changing destinations before confirmation prevents sending. The message uses the existing map-location format.
- Templates and Save template sit below composer font controls and above the text box; Templates is visible without focusing the text box.
- Live Meshtastic receptions use the receiving radio's known preset independently of packet clock skew. Same-timestamp metadata can fill an empty saved preset. Saved MT nodes without recorded settings fall back to their receiving device's known settings; explicitly recorded settings take precedence.
- Map Search nodes is inside the styled filters frame. Successful selection no longer displays a Selected status line; empty status space collapses.

Validation: node-reception, member-mode and map-position browser checks passed, including narrow/landscape/keyboard-sized viewports. Debug APK built with assembleDebug. Application ID, version and signing configuration unchanged. No publication performed.

## Follow-up: Chat device picker

The user reported that switching back after selecting a third connected device flickered and required a second selection. Chat now preserves option objects when choices are unchanged, defers picker updates while focused, and retains the requested choice through stale state publications until the native state confirms it. Changes apply to both Chat device selectors.

Validation: multi-device-098 browser regression covers three devices, switching back once on both sides, delayed native confirmation, intervening stale state updates, stable options while focused, and channels after confirmation. ## Follow-up: grouped map marker badge

Based on the user's supplied Meshtastic screenshot, grouped markers now show a short node label with a theme-coloured +N badge at the upper right. N counts additional nodes, so two nodes display +1. Single-node markers have no badge. Tapping a group still opens the complete node list, and its accessible label reports the total. Existing geographic grouping and uncertainty circles are preserved.
Locally authored markup/styles; no third-party source or assets copied. Map-position browser checks passed, including two/three-node counts and single-node absence. No APK built.

Badge colour correction: use the app accent for text/border and theme background, matching the GUI. No APK built.
